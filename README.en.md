# FixLilith

### Introduction
- Fixes the flickering issue of the desktop pet software "The NOexistenceN of Lilith"（不/存在的莉莉丝） on Linux (Proton-GE 11 + Wayland)
- Tested only on GNOME 50 Wayland and sway so far

### Known Issues
1. Mouse tracking does not work
2. The console keeps printing the error "Client area does not match virtual screen yet. ..."
3. Unable to sit on top of other windows

### Usage Guide
#### Prerequisites
- Proton-GE 11 x64 (any minor version should work in theory; this project was tested with Proton-GE 11.7 and 11.1)
- BepInEx for Unity-IL2CPP, Windows x64 build

#### Step 1: Install Proton-GE 11
1. Download Proton-GE 11. You can grab the latest x86_64 build from the official repository's [release](https://github.com/GloriousEggroll/proton-ge-custom/releases) page
2. Locate the `compatibilitytools.d` folder in the Steam root directory (create it if it doesn't exist). If you don't know where the Steam root is, pick any game in your library -> Manage -> Browse Local Files; this opens `.../Steam/steamapps/common/xxx`, where the `Steam` part in the path is your Steam root
3. Extract the downloaded Proton-GE 11 archive into `compatibilitytools.d`
4. Restart Steam, then select the newly installed Proton-GE version in the compatibility settings of this game

For a more detailed Proton-GE installation guide, refer to the README of the [official repository](https://github.com/GloriousEggroll/proton-ge-custom)

#### Step 2: Install BepInEx for Unity-IL2CPP in the game directory
1. Download the latest build of BepInEx Unity-IL2CPP-win-x64. Currently only BepInEx 6.0 bleeding edge works; you can find it [here](https://builds.bepinex.dev/projects/bepinex_be)
2. Extract the contents of the archive into the game root directory (if you don't know where it is, open your Steam library, select this game (The NOexistenceN of Lilith), go to Manage -> Browse Local Files). Note that after this step, `winhttp.dll` (BepInEx's injection DLL) should sit in the same directory as `Lilith.exe` (the game executable)
3. Add the following to the game's launch options:
  ```Launch Option
  WINEDLLOVERRIDES="winhttp=n,b" %command%
  ```
4. Launch the game once. You should see a Command Prompt window appear first and hang for a while — this is BepInEx downloading the UnityBaseLibrary on first launch; just wait until the game itself starts. If it takes too long or keeps failing, try adjusting your network configuration, or manually download the corresponding version of the UnityBaseLibrary and place the archive in the `BepInEx/unity-libs` directory. You can search for the `UnityBaseLibrariesSource` keyword in `BepInEx/config/BepInEx.cfg` to find the target URL

For a more detailed BepInEx Unity-IL2CPP installation guide, refer to the [official documentation](https://docs.bepinex.dev/master/articles/user_guide/installation/unity_il2cpp.html)

#### Step 3: Install this patch
1. Download the latest DLL file from the [release page](../../releases)
2. Find `BepInEx/plugins` in the game root directory and create a `FixLilith` folder inside it (you may rename this folder as you like — it just helps keep different patches organized)
3. Copy the DLL file into the `FixLilith` folder

#### Step 4: Other required launch options
You need to add `WINE_LAYERED_OVERLAY_ALPHA=1` to the game's launch options so that the desktop pet renders and interacts correctly. This is currently exclusive to the GE builds of Proton, which is why Proton-GE is required. The final launch options are:
  ```Launch Option
  WINEDLLOVERRIDES="winhttp=n,b" WINE_LAYERED_OVERLAY_ALPHA=1 %command%
  ```
Worth noting: `%command%` is the command generated by Steam to launch the game itself, so when adding launch options on Linux, pay attention to the order of the other parameters relative to `%command%`

### Build Guide
- Requires .NET 10. See the [official documentation](https://learn.microsoft.com/dotnet/core/install/linux?WT.mc_id=dotnet-35129-website)
- Requires BepInEx for Unity-IL2CPP
1. Clone repository (Choose one of them)
    - Github
   ```bash
   git clone https://github.com/slakrrr/fix_lilith.git
   cd fix_lilith
   ```
    - Gitee
   ```bash
   git clone https://gitee.com/slakr/fix_lilith.git
   cd fix_lilith
   ```
2. Edit fixlilith.csproj
   1. Find the line containing `<BepInEx>/home/slakr/.local/share/Steam/steamapps/common/The NOexistenceN of Lilith/BepInEx</BepInEx>` (line 11)
   2. Change it to the actual path of your BepInEx installation
3. Build
   ```bash
   dotnet build
   ```

The build output path is defined by the `<OutputPath>` item in fixlilith.csproj (line 13), and by default outputs to `BepInEx/plugins/FixLilith` under the game root directory
